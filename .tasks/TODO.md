# Postscript

Fold the agent's catch-all "Anything else?" Question into the set-level
comment box. The Set grammar gains one optional field, the Postscript:
markdown the agent closes a Set with — suggested discussion topics, or
whatever else the human might take up in their comment — rendered above the
always-present comment box instead of standing as a Question of its own. A
blank box under it means nothing to add, never Unanswered, and the Guide
reverses its standing advice that recommended the trailing catch-all.
