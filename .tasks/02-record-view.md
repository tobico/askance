# 02. The record reads the same table

## What to build

A settled Set — answered or archived unanswered — draws a table-mode
question as the same Answer Table the sheet drew, read rather than filled
in: no live radios, every row kept (what was turned down is half of what a
decision was), the chosen row carrying the treatment and the screen-reader
"chosen" that the chosen list Option carries today, and the ★ marking the
recommended row as on the sheet.

An Unanswered question, and a Set archived with no Response at all, read
exactly as they do today — the table changes how the Options are shown, not
how the outcome is said.

## Acceptance criteria

- [ ] An answered Set with a table-mode question draws the table with the
      chosen row marked, visually and to a screen reader
- [ ] A Set archived unanswered draws the table with no row marked, under
      the same head-of-page account as today
- [ ] Recommendation ★ appears in the record's table exactly as on the
      sheet; a question left Unanswered in the Response reads as today
